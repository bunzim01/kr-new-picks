# 폰트 페어링 (by @sequence_ai)

오마카세에 요리마다 술을 짝지어 주듯, 디자인에도 어울리는 폰트 짝이 있어요.
이 스킬은 **상업적으로 써도 되는 무료 폰트**만으로 짝을 골라 줘요.

## 순서

1. **물어보기(모르면 가정하고 적기)**
   - 어디에 쓰는지: 포스터 · 카드뉴스 · 상세페이지 · 썸네일 · 로고 · 발표 자료
   - 분위기 한두 마디: 차분한 · 귀여운 · 고급스러운 · 힙한 · 따뜻한
   - 갈래: 영어+영어 · 영어+한글 · 한글+한글 · 일본어+일본어 · 일본어+영어 · 일본어+한글 병기
   - 실제로 들어갈 문구
2. **짝 2~3안 고르기**
   - 먼저 `references/pairs.md`의 추천 짝 34개(기본 18 + 일본어 16)에서 찾아요.
   - 없으면 `references/fonts.md`에서 `references/rules.md`의 규칙으로 새로 짝을 지어요. 일본어가 들어가면 규칙 13~18도 지켜요.
   - 안마다 이유를 한 줄씩 붙여요(예: 「굵은 고딕 ↔ 가는 필기체, 반대끼리라 짝이 보여요」).
3. **미리보기 만들기** — 실제 문구로 그려서 눈으로 확인해요.
   ```bash
   python3 <이 스킬 폴더>/scripts/preview.py --title "Gloock" --point "DM Mono" --body "프리텐다드" \
     --head "find your|perfect|pair." --hl perfect --text "두 폰트, 한 분위기" --out preview.html
   # 일본어: 일본어 폰트를 --body 로 꼭 넣어요(기본값은 한글 프리텐다드)
   python3 <이 스킬 폴더>/scripts/preview.py --title "Zen Old Mincho" --point "Klee One" --body "Zen Kaku Gothic New" \
     --head "P:ふわっと、|T:うるおう。" --text "韓国で話題のスキンケアを、日本のあなたへ。" --out preview_ja.html
   ```
   만든 HTML은 브라우저로 열거나 캡처해서 보여 줘요(폰트는 웹폰트 주소로 불러와요).
4. **결과 카드로 정리**
   - 짝 이름과 역할: 제목 · 포인트 · 본문
   - 굵기와 크기 비율: 제목은 본문의 3배 이상
   - 설치 링크
   - 라이선스: 「상업 이용 OK」와 확인 날짜, 주의할 점(예: 폰트 파일 재배포 금지)
5. **디자인에 입히기** — 웹폰트 주소로 불러와요.
   - 영어·일본어: `fonts.json`의 `webfont_css`를 `<link>`로(일본어 문단엔 `lang="ja"`)
   - 한글: `webfont[].src`를 `@font-face`로

## 꼭 지킬 것

- **폰트 파일을 결과물이나 저장소에 복사해서 배포하지 않아요.** 설치 링크와 웹폰트 주소만 써요.
- **목록 밖 폰트를 추천할 땐 라이선스부터 확인해요.**
  - 눈누: 사용 범위 6칸
  - 구글 폰트: OFL 또는 Apache
  - 다폰트: 「100% Free」·OFL·Public domain만. 개인용(Free for personal use)은 추천하지 않아요.
- 한 화면에 폰트 3개까지. 짝은 제목 안에서 보이게 해요.
- 레퍼런스를 따라 할 땐 배치는 문법만 빌리고, 색까지 똑같이 가져오지 않아요.

## 들어 있는 것

- `references/rules.md` 짝 고르는 규칙 12개 + 일본어 규칙 6개 + 형광펜 CSS
- `references/pairs.md` 추천 짝 34개(영+영 · 영+한 · 한+한 · 일+일 · 일+영 · 일+한 병기)
- `references/fonts.md` · `references/fonts.json` 폰트 78개(한글 30 · 영어 24 · 일본어 24): 설치 링크 · 웹폰트 주소 · 라이선스
- `references/license.md` 라이선스 확인 결과와 확인 방법
- `scripts/preview.py` 짝 미리보기 HTML 만들기(파이썬 기본만 씀)
- `examples/` 예시 포스터 9장(en-en = 영+영, en-ko = 영+한, ko-ko = 한+한) + 일본어 미리보기 2장(ja-ja, ja-en) + 미리보기 예시
