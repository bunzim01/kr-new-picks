# 라이선스 확인 (2026-10-20)

이 스킬에 담은 폰트는 전부 **상업적으로 써도 되는 무료 폰트**예요.

- **영어 24개**: 구글 폰트 공식 저장소(github.com/google/fonts)의 라이선스 파일을 하나씩 열어 확인했어요. 23개 SIL Open Font License 1.1, Yellowtail 1개 Apache 2.0.
  - 둘 다 상업 이용·영상·인쇄·웹·로고 사용이 돼요. 폰트 파일만 따로 파는 것만 안 돼요.
- **한글 30개**: 눈누 폰트 페이지의 「라이선스 요약표」에서 6칸을 확인했어요. 인쇄 · 웹사이트 · 포장지 · 영상 · 임베딩 · BI/CI가 모두 「사용 가능」인 것만 넣었어요.
  - 조건이 걸린 폰트(조건부 허용·BI 금지·임베딩 금지)는 뺐어요.
- **폰트 파일**: 스킬에 들어 있지 않아요. 교보손글씨 2019처럼 파일 재배포가 금지된 폰트도 있어서, 설치 링크에서 직접 받도록 했어요.

⚠️ 눈누 안내 그대로 옮겨요. 「위 사용범위는 참고용으로, 정확한 사용범위는 이용 전 폰트 저작권자에게 확인바랍니다.」
라이선스는 바뀔 수 있어요. 큰 상업 작업 전에는 설치 링크의 원문을 한 번 더 확인하세요.

⛔ 다폰트(dafont)는 「무료」라고 적혀 있어도 개인용만인 폰트가 많아요(예: LEMON MILK는 상업용이면 기부). 다폰트 폰트를 추천할 땐 페이지 표기가 OFL · Public domain · 100% Free인지 확인한 것만 써요. 이 목록의 Bebas Neue는 다폰트 표기도 「Public domain / GPL / OFL」이에요.

## 웹폰트 주소는 어디서 왔나

스킬이 미리보기에 쓰는 웹폰트 주소는 모두 폰트 쪽이 공식으로 내놓은 주소예요. 이 저장소가 폰트를 올려 둔 곳은 없어요.
- 한글 25개: 눈누가 각 폰트 페이지의 「웹폰트로 사용」 코드로 주는 주소(cdn.jsdelivr.net/gh/projectnoonnu)
- 나눔명조 · 나눔스퀘어 네오 · 마루 부리: 네이버 한글 공식 웹폰트(hangeul.pstatic.net)
- Wanted Sans: 원티드 공식 저장소(github.com/wanteddev/wanted-sans)
- 검은고딕: 구글 폰트 공식 저장소(OFL, 재배포 허용)를 jsDelivr로 읽음
- 영어 24개: 구글 폰트 공식 웹폰트(fonts.googleapis.com)

## 법적 고지

- 이 스킬은 **폰트를 배포하지 않아요.** 폰트 파일을 담지 않고, 각 폰트의 공식 배포처 링크와 공식 웹폰트 주소만 안내해요.
- 폰트의 저작권과 이름은 각 저작권자에게 있어요. 쓸 때는 그 폰트의 라이선스를 따라야 해요.
- 이 문서의 라이선스 정리는 2026-10-20에 원문을 보고 옮긴 **참고 정보예요. 법률 자문이 아니에요.** 라이선스는 바뀔 수 있으니, 쓰기 전에 설치 링크의 원문을 확인하는 건 쓰는 사람 몫이에요.
- OFL 폰트는 폰트 파일만 따로 팔 수 없고, 고친 폰트를 원래 이름으로 내놓을 수 없어요.
- 결과물에 폰트 파일을 넣어 나눠 줄 일이 생기면(앱·템플릿 판매 등), 그 폰트의 「파일 재배포」 조건을 먼저 확인하세요. 교보손글씨 2019처럼 파일 재배포가 금지된 폰트도 있어요.
- 예시 포스터는 시퀀스스튜디오가 만든 그림이에요. 그림에 쓴 폰트는 각 라이선스가 허용하는 범위(인쇄·웹·영상 등) 안에서 썼어요.
