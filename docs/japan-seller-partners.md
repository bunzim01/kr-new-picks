### 공통 질문

모든 후보에게 1~5번을 먼저 묻는다. 이 다섯 개에서 막히면 다음 단계로 가지 않는다.

## 3. 소개 메일 초안

아직 아무에게도 보내지 않았다. 발송은 이사님이 확인한 뒤 직접 한다.

### 일본어 공통 본문

【 】 칸을 채우고, 【提案段落】 자리에 아래 유형별 단락 하나를 넣는다.

```
件名：【ご相談】韓国ブランド商品の供給・販売連携について（LIKEWAY）

【会社名】
ご担当者様

突然のご連絡失礼いたします。
韓国のLIKEWAY（ライクウェイ）で運営総括を担当しております、【氏名】と申します。

弊社は、韓国のSNS・ライブコマースで上位のセラーに商品を供給している、
複数の韓国ブランドの総代理店です。
取扱カテゴリー：【スキンケア・メイク・生活雑貨 など】

【提案段落】

まずは30分ほど、オンラインで貴社の取り組みを伺えませんでしょうか。
下記の候補日程のほか、ご都合のよい日時をご教示いただけますと幸いです。
・【候補日時①】
・【候補日時②】

必要であれば、ご面談の前に秘密保持契約（NDA）を締結させていただきます。
何卒よろしくお願い申し上げます。

──────────
【会社正式名称】 LIKEWAY
運営総括 【氏名】
【メール】 【電話】 【会社サイト】
──────────
```

한국어 뜻:

```
제목: [상담] 한국 브랜드 상품 공급·판매 협업 관련 (LIKEWAY)

[회사명] 담당자님

갑작스러운 연락 양해 부탁드립니다.
한국 LIKEWAY에서 운영총괄을 맡고 있는 [이름]입니다.

저희는 한국 SNS·라이브커머스 상위 셀러에게 상품을 공급하는
여러 한국 브랜드의 총판입니다.
취급 분야: [스킨케어·메이크업·생활잡화 등]

[제안 단락]

우선 30분 정도 온라인으로 귀사의 사업 이야기를 들을 수 있을까요?
아래 후보 일정 외에도 편하신 시간을 알려 주시면 맞추겠습니다.
· [후보 일시 ①]
· [후보 일시 ②]

필요하시면 미팅 전에 비밀유지계약(NDA)을 맺겠습니다.
잘 부탁드립니다.
```

"상위 3인"처럼 순위를 못 박지 않고 "상위 셀러"로 썼다. 첫 메일에서는 거래 셀러 이름·매출·공급가를 밝히지 않기 위해서다. 순위를 쓰려면 근거 자료를 먼저 준비한다.

### 유형별 제안 단락

| 유형 | 보낼 회사 | 핵심 제안 |
| --- | --- | --- |
| A. 상품 매입형 | トキバナ, LiveAgent | 우리를 한국 브랜드 매입처로 써 달라 |
| B. 성과보수형 | Liveee, JAPAN SOLUTIONS | 소수 SKU로 성과보수 시험 판매를 해 보자 |
| C. TikTok Shop 파트너·MCN | AnyMind, studio15, サイバーティカル, UUUM, toridori, 東京リンク, 株式会社ライバー, 売れるネット広告社 | 소속 크리에이터와 협업할 수 있는 방법을 듣고 싶다 |

**A. 상품 매입형**

```
貴社がライバーの育成から商品の仕入れまで一貫して手がけていらっしゃることを拝見し、
韓国ブランド商品の仕入れ先としてお役に立てるのではないかと考え、ご連絡いたしました。
・韓国の上位セラーが扱うブランド商品の供給
・配信用サンプルと、日本語の商品資料・訴求ポイントのご提供
・初回は少量のテスト仕入れからご相談可能です
```

뜻: 귀사가 셀러 육성부터 상품 매입까지 한번에 하신다는 것을 보고, 한국 브랜드 매입처로 도움이 될 것 같아 연락드렸다. 한국 상위 셀러가 다루는 브랜드 상품 공급, 방송용 샘플과 일본어 상품 자료 제공, 처음에는 소량 시험 매입도 가능하다.

**B. 성과보수형**

```
貴社が成果報酬型のライブ販売支援を提供されていることを拝見し、ご連絡いたしました。
弊社の取扱ブランドから数SKUを選び、短期間のテスト販売をご一緒できないかと考えております。
・商品、配信用サンプル、日本語資料は弊社でご用意します
・報酬条件や進め方は、貴社の通常の形式を伺ったうえでご相談させてください
```

뜻: 귀사의 성과보수형 라이브 판매 지원을 보고 연락드렸다. 취급 브랜드에서 몇 개 SKU를 골라 짧게 시험 판매를 해 보고 싶다. 상품·샘플·일본어 자료는 우리가 준비하고, 보수 조건은 귀사 기본 방식을 들은 뒤 정하자.

**C. TikTok Shop 파트너·MCN**

```
貴社が多くのクリエイターとともにSNS・ライブでの商品販売を支援されていることを拝見し、ご連絡いたしました。
弊社では日本市場向けに、韓国ブランド商品を販売していただけるクリエイターとの連携を検討しています。
貴社のクリエイター様と商品をつなぐ場合の進め方や条件を、ぜひ伺いたく存じます。
```
